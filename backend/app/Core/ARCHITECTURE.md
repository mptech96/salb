# MG ERP Platform Architecture

## القاعدة الذهبية
الـ Controller لا يحتوي منطق محاسبي أو مخزني أو تكلفة.
الـ Controller يستقبل الطلب فقط ويرسله إلى Business/Core.

## مسار أي عملية
UI
→ API Controller
→ Business Engine
→ Domain Engine
→ Repository
→ Database

## المحركات الأساسية
- Accounting Engine: القيود، السندات، الحسابات
- Inventory Engine: دخول وخروج وتحويل المخزون
- Cost Engine: تكلفة الحمولة، تكلفة الطن، الربحية
- Shipment Engine: دورة حياة الحمولة
- Workflow Engine: الحالات والانتقالات
- Approval Engine: الاعتمادات
- Notification Engine: التنبيهات
- Reports Engine: التقارير المالية والتشغيلية

## ممنوع
- ممنوع كتابة قيد محاسبي داخل Controller
- ممنوع كتابة حركة مخزون داخل Controller
- ممنوع حذف عملية مالية مرحلة
- ممنوع تعديل عملية مالية مرحلة إلا بعكس قيد وإعادة ترحيل
- ممنوع تكرار منطق الفواتير في أكثر من مكان

## القاعدة المحاسبية
كل عملية مالية يجب أن تنتج قيدًا متوازنًا أو تكون غير مرحلة بوضوح.

## القاعدة المخزنية
كل عملية تؤثر على الكمية تمر عبر Inventory Engine فقط.

## قاعدة تكلفة الحمولة
أي مصروف مرتبط بحمولة يدخل في Cost Engine إذا كان affects_cost = 1.

## قاعدة الفروع
شجرة الحسابات على مستوى الشركة.
الفرع يظهر في القيود والتقارير فقط.

## قاعدة الشركات
كل شركة لها حساباتها وإعداداتها الخاصة.
